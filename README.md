# ACEX — RadIA

Sistema acadêmico de apoio à análise radiológica. Consulte a documentação de integração da IA em [`radIA_v3/radIA/README.md`](radIA_v3/radIA/README.md).

## RadIA

A aplicação principal está em `radIA_v3/radIA/index.html`. Para desenvolvimento local:

```bash
python3 -m http.server 8000 --directory radIA_v3/radIA
```

Abra `http://localhost:8000/`. O arquivo `radIA26-10.html` permanece como referência histórica do protótipo usado como base visual e funcional.
